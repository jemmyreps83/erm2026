# Mapa de resultados ERM 2026

Portal interactivo de las **Elecciones Regionales y Municipales 2026 del Perú**: partido político en primer lugar por región (gobernador), provincia y distrito (alcaldías), con votos, ventaja y detalle por candidato.

**Ver el mapa:** abra `index.html` publicado con GitHub Pages.

- Fuente: ONPE, Presentación de resultados ERM 2026.
- Ocupar el primer lugar en el conteo no equivale a la proclamación del Jurado Electoral Especial (JEE).
- Elaboración: Good Guys Insight.
